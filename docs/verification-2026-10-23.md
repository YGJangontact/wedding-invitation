# 시안 추가 검증

- 6개 테마 각각 320px / 390px 브라우저 viewport에서 DOM 전체 폭과 내용 폭 일치. 세 새 시안의 첫 예식 안내 끝은 화면 상단 기준 571~634px로 844px 높이 안에 표시됨.
- 기존 garden/classic/minimal 경로와 기본 garden 유지.
- 접힌 디자인 메뉴에서 6개 후보 및 비교 페이지 이동 확인. 비교 페이지 6개 미리보기와 모바일 가로 넘침 없음 확인.
- 주소 복사 성공 메시지와 복사 대상 확인. 주차 안내 펼침 및 달력 예식일 9 표시 확인.
- 로컬에서 네이버 타일·마커 로드 완료 확인. 지도 실패 시 외부 링크를 남기는 기존 코드는 유지.
- GitHub Pages base 경로로 정적 8개 페이지 빌드 성공. 빌드 HTML의 내부 src/href 파일 대상 존재 확인.
- 달력의 불완전한 table/row ARIA 역할을 날짜 안내 그룹으로 수정.

실제 스마트폰 OS 공유창, 사진 확대는 이번 검증 범위 밖. 현재 대표 사진과 사진첩 데이터가 비어 있으며, 실제 이름·사진을 넣은 뒤 줄바꿈·사진 크롭을 다시 확인해야 함.
